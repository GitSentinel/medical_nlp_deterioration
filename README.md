# Temporal NLP for Predicting Disease Progression from Longitudinal Electronic Health Records Using Transformer Models

This repository contains the coursework project for **SCC.453 – Natural Language Processing** at **Lancaster University**.

The project investigates whether transformer-based NLP models can predict **30-day hospital readmission** as a proxy for clinical deterioration, using temporally-structured narratives derived from real de-identified electronic health records.

## Research Question

> Can transformer-based NLP models applied to temporally-structured clinical narratives derived from longitudinal EHR data outperform traditional NLP baselines in predicting 30-day hospital readmission?

---

## Project Overview

Healthcare systems generate large volumes of patient data over time — diagnoses, medications, laboratory measurements, and clinical encounters. Predicting how a patient's condition will evolve is clinically valuable but difficult due to the heterogeneous and temporal nature of EHR data.

This project takes a **temporal NLP approach**: structured records from the **MIMIC-IV Clinical Database Demo** are converted into chronologically-ordered narrative summaries, which are then used to fine-tune transformer models for readmission prediction. Three transformer architectures are compared against traditional TF-IDF baselines.

## Models Evaluated

| Model | Type | Pre-training Domain |
|-------|------|---------------------|
| TF-IDF + Logistic Regression | Baseline | — |
| TF-IDF + Random Forest | Baseline | — |

| DistilBERT | Transformer | General English text |
| PubMedBERT | Transformer | PubMed abstracts (biomedical) |
| BioBERT | Transformer | PubMed + PMC full-text |

## Getting Started

### 1. Clone

```bash
git clone https://github.com/GitSentinel/medical_nlp_deterioration.git
cd medical_nlp_deterioration
```

### 2. Environment

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
```

### 3. Dataset

See `data.txt` for full instructions. Download MIMIC-IV Demo from PhysioNet and extract to `data/raw/mimic-iv-clinical-database-demo-2.2/`.

### 4. Run Notebooks

Run in order: `01 → 02 → 03 → 04 → 05a → 05b → 05c → 06`

> **GPU note:** Notebooks 05a–05c are computationally intensive. Recommended: Google Colab with T4 GPU (Runtime → Change runtime type → T4 GPU). Upload the notebook and `data/processed/labelled_dataset.csv`.

## Ethical Considerations

This project uses the MIMIC-IV Clinical Database Demo, which contains de-identified data from real patients. Access requires a PhysioNet account and agreement to the Credentialed Health Data License. No attempt is made to re-identify individuals. Results are reported at aggregate level only.
