## Project Overview

This project converts structured records from **MIMIC-IV v3.1** into chronologically ordered clinical narratives, then fine-tunes transformer models to predict 30-day readmission as a proxy for clinical deterioration. Three transformer architectures (DistilBERT, PubMedBERT, BioBERT) are compared against TF-IDF baselines. All transformer training is GPU-accelerated (CUDA).

Key v3.1 features used:
- `omr` table (height, weight, BMI, blood pressure) enriches narratives
- `dod` (date of death) used to exclude in-hospital deaths from label construction
- 2020-2022 cohort provides contemporary clinical data

## Getting Started

```bash
git clone https://github.com/GitSentinel/medical_nlp_deterioration.git
cd medical_nlp_deterioration

python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # macOS / Linux

pip install -r requirements.txt
```

Verify CUDA is available:
```python
import torch
print(torch.cuda.is_available())      # True
print(torch.cuda.get_device_name(0))  # e.g. NVIDIA GeForce RTX 3080
```

Set up MIMIC-IV v3.1 data (see `data.txt`), then run notebooks in order: `01 -> 02 -> 03 -> 04 -> 05a -> 05b -> 05c -> 06`.
