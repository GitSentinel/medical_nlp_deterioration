DATASET INFORMATION
===================

Dataset : MIMIC-IV v3.1
Source : PhysioNet
URL : https://physionet.org/content/mimiciv/3.1/
DOI : https://doi.org/10.13026/kpb9-mt58
License : PhysioNet Credentialed Health Data License 1.5.0
Access : Credentialed PhysioNet account required (CITI training + DUA)
Published : October 11, 2024

Description
-----------
MIMIC-IV is a large, freely accessible de-identified EHR dataset for
patients admitted to the emergency department or an intensive care unit
at Beth Israel Deaconess Medical Center (BIDMC), Boston, MA. v3.1 covers admissions from 2008 to 2022.

Tables Used in This Project
---------------------------
hosp/patients.csv.gz (Patient demographics (anchor_age, gender, dod))
hosp/admissions.csv.gz (Admission and discharge timestamps)
hosp/diagnoses_icd.csv.gz (ICD-10/9 diagnoses per admission)
hosp/d_icd_diagnoses.csv.gz (ICD code to human-readable title lookup)
hosp/prescriptions.csv.gz (Medication prescriptions with dates)
hosp/labevents.csv.gz (Laboratory test results with timestamps)
hosp/d_labitems.csv.gz (Lab item ID to label lookup)
hosp/omr.csv.gz (Outpatient measurements: height, weight, BMI, BP)
icu/icustays.csv.gz (ICU stay records with LOS)

Prediction Target
-----------------
Binary 30-day readmission:
  Label = 1 if re-admitted within 30 days of discharge
  Label = 0 otherwise
Derived entirely from admission timestamps. In-hospital deaths excluded
from the positive class (patient cannot be "readmitted" if they died).

Setup Instructions
------------------
1. Create a credentialed account at https://physionet.org
2. Complete CITI training 
3. Sign the MIMIC-IV data use agreement on PhysioNet
4. Download MIMIC-IV v3.1 from the URL above
5. Extract to:
       data/raw/mimic-iv-3.1/
   Confirm structure:
       data/raw/mimic-iv-3.1/hosp/admissions.csv.gz   
       data/raw/mimic-iv-3.1/icu/icustays.csv.gz      
6. Run notebooks in order: 01 -> 02 -> 03 -> 04 -> 05a -> 05b -> 05c -> 06
